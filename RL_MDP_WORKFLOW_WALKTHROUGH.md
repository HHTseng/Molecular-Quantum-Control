# RL-QLS Python code: RL/MDP workflow walkthrough

This document explains how the implementation maps the molecular quantum-control problem into a Gymnasium environment and how the PyTorch DQN agent interacts with it.

## 1. Four software layers

The project is divided into four layers:

1. **Quantum-physics preprocessing**
   - Build the pulse-conditioned measurement matrices \(B_{a,k}\).
   - Files: `src/rlqls/materials.py`, `src/rlqls/qutip_builder.py`.
2. **Finite MDP transition model**
   - Evaluate branch probabilities and conditional molecular populations.
   - File: `src/rlqls/model.py`.
3. **Interactive Gymnasium environment**
   - Sample one measurement result and return the next RL observation.
   - File: `src/rlqls/env.py`.
4. **DQN/qMDP optimization**
   - Select pulse actions, collect transitions, train the Q-network, and evaluate the learned policy.
   - Files: `src/rlqls/dqn.py`, `src/rlqls/evaluation.py`.

The overall data flow is

```text
molecular Hamiltonian + pulse library
        |
        v
branch matrices B[a,k]
        |
        v
Gym state s_t --DQN--> pulse a_t --environment--> measurement k_t
        ^                                           |
        |                                           v
        +------------- conditional state s_(t+1) ---+
```

## 2. MDP definition

Let \(N\) be the number of molecular internal eigenstates and \(A\) the number of pulse actions.

### 2.1 State / observation

The RL state is the molecular posterior population vector

$$
s_t = (P_{t,1},\ldots,P_{t,N})^{\mathsf T}
\in \Delta_{N-1},
$$

where

$$
\Delta_{N-1}
=
\left\{s\in\mathbb R_{\geq0}^{N}:\mathbf 1^{\mathsf T}s=1\right\}.
$$

The component \(P_{t,i}\) is the inferred probability that the molecule is in internal eigenstate \(|i\rangle\), conditioned on the pulse and measurement history.

In code:

```python
self.observation_space = spaces.Box(
    low=0.0,
    high=1.0,
    shape=(model.n_states,),
    dtype=np.float32,
)
```

Gymnasium has no built-in simplex space, so `Box` encodes only the component bounds. `normalize_probability` enforces \(\sum_i P_{t,i}=1\).

The observation is **not** the binary motional result \(k_t\). The raw result is stored in `info["measurement_outcome"]`; the agent receives the updated posterior \(s_{t+1}\).

### 2.2 Action

The action is a discrete pulse index

$$
a_t\in\mathcal A=\{0,\ldots,A-1\}.
$$

In code:

```python
self.action_space = spaces.Discrete(model.n_actions)
```

Each action selects one Raman blue-sideband pulse, including its inferred or calibrated frequency, duration, polarization, and coupling pattern. The measurement is not selected by the agent.

### 2.3 Transition probability

For each pulse \(a\) and binary motional outcome \(k\in\{0,1\}\), define

$$
(B_{a,k})_{ji}
=
\sum_{n\in\mathcal N_k}
\left|\langle j,n|U_a|i,0\rangle\right|^2.
$$

Here

- \(|i,0\rangle=|i\rangle_{\mathrm{mol}}\otimes|0\rangle_{\mathrm{mot}}\);
- \(U_a\) is the unitary generated by pulse \(a\);
- \(\mathcal N_0=\{0\}\);
- \(\mathcal N_1\) contains retained excited motional Fock states, usually all \(n\geq1\) in the truncated basis.

For an incoming population \(s\), the unnormalized branch population is

$$
q_{a,k}=B_{a,k}s.
$$

The probability of the projective measurement result is

$$
p(k\mid s,a)=\mathbf 1^{\mathsf T}q_{a,k}.
$$

The conditional next state is

$$
F_{a,k}(s)=\frac{q_{a,k}}{p(k\mid s,a)}.
$$

The implementation is in `BranchModel.branches`:

```python
raw = np.matmul(maps, s)          # q_(a,k), shape (2,N)
raw_mass = raw.sum(axis=1)        # p(k|s,a), shape (2,)
next_states[k] = raw[k] / raw_mass[k]
```

The physical stochastic kernel is therefore

$$
\Pr(s_{t+1}=F_{a,k}(s_t)\mid s_t,a_t=a)=p(k\mid s_t,a).
$$

### 2.4 Reward

The default reward is

$$
r_{t+1}=-1
$$

for every pulse-measurement step. If an episode terminates after \(T\) steps, the undiscounted return is \(-T\), so maximizing expected return minimizes expected preparation time.

For the larger H\(_3\)O\(^+\) model, an optional penalty is added if the pulse barely changes the population:

$$
o(s,s')
=
\frac{s^{\mathsf T}s'}{\|s\|_2\|s'\|_2},
$$

$$
r(s,a,k)
=
-1-r_o\,
\mathbf 1\left\{o(s,F_{a,k}(s))>1-\frac1N\right\}.
$$

The overlap trigger is stated in the supplement. The precise additive reward formula is not printed, so this implementation is explicitly an assumption.

### 2.5 Termination and truncation

Physical task success is

$$
\max_i P_{t,i}\geq1-\eta,
$$

where \(\eta\) is the preparation-infidelity threshold.

In code:

```python
def is_terminal(self, state):
    return np.max(state) >= 1.0 - self.infidelity_threshold
```

`terminated=True` means this physical condition was reached. `truncated=True` means only that the artificial `max_steps` simulation cutoff was reached.

The reproduction configuration treats truncation as absorbing failure when computing Bellman targets. Set `DQNConfig.bootstrap_on_truncation=True` to bootstrap across the cutoff instead.

## 3. How the branch matrices encode the quantum physics

### 3.1 Exact route

With a complete Hamiltonian, `qutip_builder.py` solves

$$
U_a
=
\mathcal T\exp\left[-\frac{i}{\hbar}
\int_0^{\tau_a}H_a(t)\,dt\right].
$$

For every molecular input state \(|i\rangle\), it propagates

$$
|i,0\rangle
\longmapsto
U_a|i,0\rangle
=
\sum_{j,n}c^{(a)}_{j n;i}|j,n\rangle.
$$

It then constructs

$$
(B_{a,k})_{ji}
=
\sum_{n\in\mathcal N_k}|c^{(a)}_{j n;i}|^2.
$$

The code retains coherent amplitudes during propagation and discards phase only when forming the post-measurement population model.

### 3.2 CaH\(^+\) surrogate

`build_cah16_surrogate` uses the dominant directed transitions shown in Supplemental Fig. S2. A listed transfer

```python
(source, target, probability)
```

means approximately

$$
|\mathrm{source},0\rangle
\to
|\mathrm{target},1\rangle
$$

with the stated probability. This is a population model, not an exact multilevel Hamiltonian calculation.

### 3.3 H\(_3\)O\(^+\) surrogate

`_coherent_motional_map` uses the product basis

$$
|i,n\rangle=|i\rangle_{\mathrm{mol}}\otimes|n\rangle_{\mathrm{mot}}
$$

and a rotating-frame blue-sideband coupling

$$
|i,n\rangle\leftrightarrow|j,n+1\rangle,
$$

with matrix element proportional to

$$
\frac{\eta\Omega_{ij}}{2}\sqrt{n+1}.
$$

It computes a local unitary with `scipy.linalg.expm`, then aggregates \(n=0\) into branch \(k=0\) and all retained \(n\geq1\) into branch \(k=1\).

The exact 218 pulse definitions are unavailable; clustering, pulse centers, durations, and local detuning windows are inferred.

## 4. One Gym environment step

`RLQLSEnv.step(action)` executes the following sequence.

### Step 1: obtain all branches

```python
details = self.branch_details(old_state, action)
```

This computes

- `details.probabilities[k] = p(k|s_t,a_t)`;
- `details.next_states[k] = F_(a_t,k)(s_t)`;
- branch rewards;
- branch terminal flags.

### Step 2: sample the motional measurement

```python
outcome = self.np_random.choice(2, p=details.probabilities)
```

The pulse controls the probability distribution, but the agent cannot choose the projective measurement result.

### Step 3: condition the molecular state

```python
self._state = details.next_states[outcome]
```

This is the Bayesian/post-measurement update.

### Step 4: return the Gym tuple

```python
return next_state, reward, terminated, truncated, info
```

`info` includes the realized measurement bit and all counterfactual branches. The counterfactual data are useful for diagnostics; qMDP training recomputes them directly from the branch matrices on the PyTorch device.

## 5. How DQN receives a state and chooses a pulse

The network is

```python
QNetwork(N, A, hidden_sizes=(128,128,128))
```

and implements

$$
Q_\theta:\Delta_{N-1}\to\mathbb R^A.
$$

Given a state batch of shape `(batch,N)`, its output has shape `(batch,A)`:

```python
q_values = online(states)
```

For one state, the greedy pulse is

```python
action = q_values.argmax(dim=1)
```

or mathematically

$$
a_t=\arg\max_a Q_\theta(s_t,a).
$$

During training, epsilon-greedy exploration is used:

```python
if random_number < epsilon:
    action = random pulse
else:
    action = argmax_a Q_theta(state,a)
```

Exploration randomizes the **pulse selection**. It does not randomize or control the measurement result beyond the physical distribution already induced by that pulse.

## 6. Replay-buffer interaction loop

The essential training loop is

```python
state, _ = env.reset()
while not (terminated or truncated):
    action = epsilon_greedy(Q_online, state)
    next_state, reward, terminated, truncated, info = env.step(action)
    replay.append(state, action, reward, next_state, flags)
    state = next_state
    optimize_from_replay()
```

A replay item contains

$$
(s_t,a_t,r_{t+1},s_{t+1},\mathrm{terminated},\mathrm{truncated}).
$$

This makes the algorithm off-policy: old transitions can be reused after the network has changed.

## 7. Sampled DQN versus qMDP DQN

### 7.1 Sampled Double DQN

The sampled target uses only the outcome that occurred during `env.step`:

$$
y_{\mathrm{sample}}
=
r_{t+1}
+
\gamma(1-d_{t+1})
Q_{\bar\theta}
\left(
 s_{t+1},
 \arg\max_{a'}Q_\theta(s_{t+1},a')
\right).
$$

In code:

```python
chosen_actions = online(next_states).argmax(dim=1, keepdim=True)
values = target(next_states).gather(1, chosen_actions)
target_value = rewards + gamma * (1.0 - done) * values
```

The online network \(Q_\theta\) selects the action and the target network \(Q_{\bar\theta}\) evaluates it; this is the Double-DQN decomposition.

### 7.2 Expected-branch qMDP Double DQN

For a replayed pair \((s,a)\), qMDP reconstructs both branches:

$$
s'_k=F_{a,k}(s),
\qquad
p_k=p(k\mid s,a).
$$

The target is

$$
y_{\mathrm{qMDP}}
=
\sum_{k=0}^{1}p_k
\left[
 r_k+
 \gamma(1-d_k)
 Q_{\bar\theta}
 \left(
   s'_k,
   \arg\max_{a'}Q_\theta(s'_k,a')
 \right)
\right].
$$

The code path is `_qmdp_target_torch`.

A subtle but important point: the environment trajectory still samples one real outcome. qMDP changes only the training target by integrating over all known outcomes. Thus exploration of state trajectories remains stochastic, while the temporal-difference target has lower branch-sampling variance.

## 8. Gradient update

For a minibatch, the network prediction is

```python
prediction = online(states).gather(1, actions[:, None]).squeeze(1)
```

which selects \(Q_\theta(s_b,a_b)\) for every replay item \(b\).

The loss is Smooth L1 by default:

```python
loss = F.smooth_l1_loss(prediction, expected)
```

Then

```python
optimizer.zero_grad()
loss.backward()
clip_grad_norm_(online.parameters(), max_norm)
optimizer.step()
soft_update(target, online, tau)
```

The target parameters are updated by

$$
\bar\theta
\leftarrow
(1-\tau)\bar\theta+\tau\theta.
$$

## 9. Evaluation

During evaluation, epsilon is removed. The policy is deterministic in the posterior state:

$$
\pi(s)=\arg\max_aQ_\theta(s,a).
$$

The episode remains stochastic because the motional measurement outcome is sampled at each step.

`evaluate_network_batched` vectorizes many Monte Carlo episodes. `evaluate_sweeping_batched` applies a fixed periodic pulse order as the reference policy.

## 10. What is exact and what is inferred

### Paper-faithful control/RL structure

- population-vector state;
- discrete pulse action;
- binary measurement branch;
- conditional state update;
- reward \(-1\) per step;
- confidence-based termination;
- three hidden layers with 128 units;
- replay, target network, epsilon-greedy DQN;
- expected-branch qMDP target.

### Inferred or implementation-specific

- normalization suppressed in the paper's compact Eq. (4b) is made explicit;
- exact combination of qMDP and Double DQN;
- additive form of the overlap penalty;
- corrected epsilon-decay sign;
- treatment of the artificial max-step truncation;
- CaH+ weak/off-resonant channels;
- H3O+ pulse grouping, pulse centers, durations, and local coherent windows.

```bash
  --material cah \
  --steps 8 \
  --seed 4
```

```bash
PYTHONPATH=src python scripts/trace_one_episode.py \
  --material cah \
  --steps 20 \
  --seed 4 \
  --checkpoint results/checkpoints/cah_qmdp_1000_seed7.pt
```
